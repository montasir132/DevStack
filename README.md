# 🚀 Dev Stack Builder

A modern web application to **build and explore your ideal technology stack**.  
Easily select frontend, backend, and database tools, compare them side by side, and manage your stack with a clean interface.

---

## 🛠️ Technologies You Can Use
- **React.js** – Component-based frontend framework  
- **Tailwind CSS + DaisyUI** – Utility-first styling with ready-made UI components  
- **TypeScript / JavaScript (ES6+)** – Strongly typed or modern JS features  
- **React-Toastify (NPM Package)** – Toast notifications for user feedback  
- **JSON** – Technology data storage and loading  
- **Vite** – Fast build tool and development server  

---

## ✨ Features
1. **Interactive Stack Management** – Add or remove technologies dynamically with instant UI updates.  
2. **Empty State Handling** – Displays a friendly message when no technologies are selected.  
3. **Persistent Data Loading** – Uses hooks to fetch and display JSON-based technology data.
